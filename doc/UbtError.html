Build Error Class

The Universal Build Tool error class defines an error with an error code and optional detail.

Module Status:

new UbtError(cod,msg,dtl)

Create a UbtError with the specified code, message, and optional detail.

wrap(err, dtl)

Wraps an error into a UbtError, retaining the original call stack, allowing optional detail to be added. The error code is the name of the original error, the message is it’s message or it string representation, and the optional properties to add to the new error.

NB: If the error is already a UbtError the same error is returned, with the optional detail appended (if any).
